# ⚖️ Jurídico Torres - Sitio Web Profesional para Estudio Jurídico

Sitio web profesional desarrollado con Django para un estudio jurídico, enfocado en presencia institucional, diseño moderno y contacto rápido con clientes.

🌐 Sitio web: https://juridicotorres.com/

---

# 📌 Características

- Landing page profesional
- Diseño responsive
- Presentación de áreas legales
- Integración con WhatsApp
- Navegación intuitiva
- Diseño institucional moderno
- Optimización para dispositivos móviles
- Deploy online

# ⚙️ Instalación local

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/pedrinio10/juridico-web.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd juridico-web
```

---

## 3️⃣ Crear entorno virtual

```bash
python -m venv venv
```

---

## 4️⃣ Activar entorno virtual

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

---

## 5️⃣ Instalar dependencias

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Ejecutar servidor

```bash
python manage.py runserver
```
